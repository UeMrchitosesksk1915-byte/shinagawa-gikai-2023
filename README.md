# 2023年 品川区議会議員選挙 当選者の主要政策まとめ

2023年4月23日に行われた品川区議会議員選挙（定数40人、立候補58人、投票率40.86%）の当選者40人について、主要政策を3つずつまとめたものです。

2023年当時の選挙公報はネット上に残っていないため、各議員の公式サイト・所属政党のページ・選挙ドットコムなどの公開情報から集めています（2026年11月時点で調査）。

## 注意点

- **当選者の一覧**：選挙ドットコムの得票数の上位40人です。品川区の公式発表と1人ずつ照合はできていません。
- **2023年の公約だと確認できたのは9人だけ**（◎の人）です。○や△の人はページに日付がなく、現在の内容や別の時期の内容が混ざっている可能性があります。
- **政策が見つからなかった7人**は、発信がFacebookやXなどSNS中心で、そこまでは確認できていません。
- 党派は2023年選挙時のものです。その後の離党・転身などは一部しか反映していません。
- 正確な2023年の公約が必要な場合は、品川区選挙管理委員会で当時の選挙公報を閲覧してください。
- 誤りに気づいた場合は Issue などでお知らせください。
